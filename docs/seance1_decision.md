# Décision pour CampusFlow

La cible de CampusFlow est l'étudiant francophone en Afrique, qui dispose le plus souvent d'un smartphone Android d'entrée ou de moyenne gamme, avec une connexion mobile intermittente et un budget limité ; la fiche comparative montre en effet que le coût appareil, la fragmentation et la connectivité sont les contraintes les plus fortes dans ce contexte, tandis que l'autopsie de Windows Phone montre qu'une plateforme fermée sans catalogue d'applications ni perspective de long terme ne peut pas être retenue. Nous publierons donc d'abord sur Android via le Play Store, avec iOS comme cible secondaire si les moyens le permettent, et nous conservons le web comme accès de repli. L'approche retenue est le cross-platform avec Flutter : un seul code source pour Android et iOS, un rendu cohérent sur les écrans 360 dp et 840 dp déjà prévus dans l'application, des données stockées localement pour fonctionner hors ligne, et une équipe étudiante limitée qui évite de maintenir deux applications natives distinctes.
